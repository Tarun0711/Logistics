# Logistics

Scroll-driven 3D story for ELIV Logistics, built with Three.js, GSAP and Vite:
a parcel is loaded into a container, the container is lifted onto a truck,
driven to the port, craned aboard a container ship, and sails out to sea.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build` (output in `dist/`).
